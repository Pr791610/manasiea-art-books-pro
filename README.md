# ART&BOOKS HUB

## Digital Art, Books & Museum Hub

ART&BOOKS HUB is a digital platform for presenting art, books, certificates, photographs, videos, museum content and related digital experiences.

### Project Structure

```text
ART&BOOKS HUB/
│
├── index.html
├── README.md
├── LICENSE
│
└── assets/
    ├── images/
    └── videos/
```

### Media

Images are stored in:

```text
assets/images/
```

Videos are stored in:

```text
assets/videos/
```

### Main Page

```text
index.html
```

The `index.html` file is the main HUB page and connects the project's galleries, books, certificates, videos, photographs and other sections.

### Deployment

The project is designed for deployment through Netlify and can be connected directly to its GitHub repository.

```text
ART&BOOKS HUB
      ↓
   GitHub
      ↓
   Netlify
      ↓
  Live Website
```
